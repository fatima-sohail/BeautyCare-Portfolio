# Project Workbook

The Google Sheets workbook contains the detailed planning data for the Beauty Product Management Portfolio.

It is the source of record for the project’s Product Backlog and sprint planning. The workbook is organized into two tabs:

1. **Product Backlog** — contains the full prioritized list of user stories across the Skincare, Haircare, and Makeup epics.
2. **Sprint Backlog** — contains the user stories selected for Sprint 1 and Sprint 2, including sprint dates, capacity, assigned story points, and value comparison.


## Workbook Contents

The workbook includes:

- Prioritized Product Backlog
- Skincare, Haircare, and Makeup epics
- Customer personas
- User stories and acceptance criteria
- Customer and business value ratings
- Story-point estimates
- Sprint 1 (Current Sprint) Backlog
- Sprint 2 (Next Sprint) Backlog
- Sprint capacity, assigned points, and value comparison
