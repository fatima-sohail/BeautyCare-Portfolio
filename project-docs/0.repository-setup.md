## Repository Setup

I created the `BeautyCare-Portfolio` repository on GitHub to organize and present the project documentation, backlog workbook, images, sprint materials, and lessons learned.

The repository was initially created with a root `README.md` file. The README serves as the main project overview and provides links to the supporting project documentation.

## Local Workspace Setup

After creating the repository on GitHub, I cloned it to my local computer using IntelliJ IDEA.

In IntelliJ IDEA, I used **File → New → Project from Version Control → Git**, pasted the repository URL, selected a local folder, and cloned the repository.

Working locally in IntelliJ IDEA allowed me to create and edit Markdown files, organize project folders and images, review changes, and publish updates to GitHub through Git.

## GitHub Desktop Workflow

GitHub Desktop was used to track changes and publish updates to GitHub.

The workflow was:

1. Edit or create Markdown files and add images in IntelliJ IDEA.
2. Save the changes locally.
3. Open GitHub Desktop and review the changed files.
4. Add a clear commit summary describing the update.
5. Commit the changes to the local repository.
6. Push the commit to the GitHub repository.
